# Classmate Unity C# Code Inspection Workspace

This workspace is designed for safely inspecting, linting, and analyzing Unity C# code from classmates. It is configured for trusted use and extensibility.

## Usage
- Place Unity C# projects or scripts in subfolders as needed.
- Use the recommended extensions for code analysis and linting.
- Review code, run analyzers, and document findings in this workspace.

## Recommended Extensions
- C# (by Microsoft)
- Unity Tools (by Tobiah Zarlez or Unity Technologies)
- EditorConfig for VS Code

## Trust & Security
This workspace is intended to be marked as trusted in VS Code. Only open code from classmates you trust.
